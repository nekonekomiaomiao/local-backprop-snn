## Current Discipline

1. Run all scripts with `python3`, not `python` (the container has no such command).
2. For long tasks use `setsid nohup python3 ... &` and write to the experiment directory's `run_log.txt`.
3. Training scripts may only tolerate mid-run interruption once they have periodic checkpoints.
4. Keep parallel processes ≤4 and monitor memory with `free -h` at all times (training RSS ~270MB/process).
5. **0.8 achieved (control reset 0.824 / realistic LIF+ISI recalibrated multi-seed ≥0.8); acceptance uniformly uses the multi-seed frozen evaluation (`eval_multiseed.py`, 5×n=500, τ_m=0.5/ISI=100 readout)**.
